# 作者风格档案索引

> 每个作者一个 `.md` 文件，按作者名命名。调用时 `ls` 列出可用档案，按需读取。
> 重量级档案（v2.0+）标注 ⭐，轻量级（v1.0 已弃用）标注 ⚠️ deprecated。

## 档案结构

每个作者档案包含（详见 `author-profiling` skill）：

1. 叙述者声音肖像 — 语调范围 / 幽默机制 / 情感距离控制
2. 情节设计模式 — 驱动类型 / 冲突偏好 / 高潮模式 / 情节模板
3. 关系设计模式 — 核心关系类型 / 关系组合模板 / 推进节奏
4. 常用技法清单 — 开头/桥段/断章/事件展开/特殊技法
5. 世界观设计风格 — 构建方式 / 规则密度 / 社会结构
6. 大纲模板 — 全书结构 / 章节模板 / 节奏模板 / 信息释放节奏
7. 语言指纹 — 句长分布 / 词汇偏好 / 标点特征 / 比喻密度

## 5 维正交加载机制（v5 修订——5 维正交化最终版）

```
5 维正交：
0. 体裁（genre）= 顶层分类（轻小说 / 网文 / 严肃文学）—— 自动从基底推断
1. 主题（theme）= 题材域选择（8 主题族，可叠加）—— 必填
2. 基底（base）= 跨主题跨体裁的句法骨架（7 坐标轴，2 选 1）—— 必填 1 个
3. 风格（style）= 作者特定的叙述态度+域词+桥段选择（6 作家风格层）—— 可选
4. 子变体（subvariant）= 单作品特定细粒度（嵌入风格层文件）—— 可选
5. 题材特化（specialization）= 题材域白名单/特殊变体（按需）—— 可选

组合 = 基底 × 主题叠加 × 风格 × 子变体 × 题材特化（完全独立正交）
```

## 跨作家共性对照

详见 `docs/refactor/作家档案工程值表.md`——按 L1 网络原生共性 / L2 题材谱 / L3 作家特定 / L4 单作品特定 四维分层。

## 使用场景

- **写作流启发式交谈**：提供"如果是 XX 作者会如何写"视角
- **改编流风格对标**：L1（文风移植）时作为目标风格约束
- **「墨」写作**：参照作者档案的叙述者声音和语言指纹
- **「铃」风格把关**：将作者档案的语言指纹作为额外检查维度

## 加载机制

工程加载风格档案的优先级：
1. **L1 网络原生共性**（自动加载，不可关闭）
2. **L2 题材/世界观密度谱**（按 `style_profile_type` 加载）
3. **L3 作家特定**（按 `style_profile_variant` 加载）
4. **L4 单作品特定**（按 `style_profile_subvariant` 加载）
