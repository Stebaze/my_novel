# 日轻共性基底 v1.2（5 维正交化——只装跨主题坐标轴）

> **核心设计原则**：本基底是**坐标系**——只装 7 个跨主题跨体裁的"句法坐标轴"。**绝不装**任何主题/题材相关项（桌游/学园/电玩/推理/末日/科幻等）。
>
> **5 维正交**：基底 × 主题 × 风格 × 子变体 × 题材特化 = 完全独立可叠加。
>
> **v1.2 vs v1.1**：v1.1 误把"5-8 角色小群体/小光谱+角色选择/极简现实/物理小物作潜台词/领域沉浸"等**主题相关项**当成了基底——这些项**已全部移除到 `_themes/` 主题层**。v1.2 只保留 7 个真正跨主题通用的句法坐标轴。

---

## 零、基底定位

**本基底的工程作用**：当作者选择"日轻向"项目时，工程默认加载本基底作为"句法骨架"。**不强制**任何主题/题材/作家风格——可与 `_themes/` 主题层 + `_styles/` 风格层独立正交叠加。

**7 坐标轴全向"短/小/简"侧配置**：
- POV = 第一人称
- 推进单位 = 关系-对话驱动
- 句法 = 短句+极短段
- 内心通道 = 自由间接引语
- 关系网规模 = 5-8 角色
- 高潮模式 = 小光谱+角色选择
- 世界观密度 = 极简

这 7 选 7 全向"短/小/简"侧 = **日轻共性基底的本质**。

## 一、基底层（7 坐标轴）——唯一不可变层

> **基底层是工程默认加载的硬约束**。违反任一轴 = 不属于"日轻"范畴。

### 坐标轴 1：POV = **第一人称**

| 维度 | 约束 |
|------|------|
| 人称 | 第一人称（POV=我）|
| 叙述者数量 | 单 POV 为主（多 POV 切换 ≤ 30%）|
| 与读者关系 | 自嘲式亲密（沿用"短/小/简"侧基线）|

**反例**（违反 = 不属于日轻）：第三人称全知、多POV 平权、第四面墙直呼读者
**主题相关项（应移至 _themes/）**：第一人称"自嘲"是叙述态度（风格层）而非 POV 维度（基底层）

### 坐标轴 2：推进单位 = **关系-对话驱动**

| 维度 | 约束 |
|------|------|
| 大纲设计推进单位 | 两个角色的一个完整互动 |
| 事件依赖 | 事件依附于关系（不是关系依附于事件）|
| 跨章衔接 | 情感延续+软性开场+无声收尾 |

**反例**（违反 = 不属于日轻）：岛弧/末日仪式/系统模拟作为推进单位
**主题相关项（应移至 _themes/）**：桌游/电玩/委托/推理 等"领域装置"是主题层（题材域），不是基底

### 坐标轴 3：句法 = **短句+极短段**

| 维度 | 约束 |
|------|------|
| 平均句长 | 13-25 字（短句为主）|
| 段均句数 | 1-3 句（极短段）|
| 段长极短（1 句）占比 | 30-70% |
| 长段（>6 句）占比 | < 5% |

**反例**（违反 = 不属于日轻）：平均句长 30+ 字、段均 5+ 句、长段 10%+
**主题相关项（应移至 _themes/）**：具体句长数字（13.5/16/22.4）是风格层

### 坐标轴 4：内心通道 = **自由间接引语为主**

| 维度 | 约束 |
|------|------|
| 主通道 | 第三人称带角色腔调（无"他想/觉得"标签）|
| 占比 | 自由间接引语 50%+ |
| 备选通道 | 第一人称直接内心、括号补充——但**不应取代**自由间接引语为主地位 |

**反例**（违反 = 不属于日轻）：70%+ 叙述者抒情、系统「」作为主内心通道
**主题相关项（应移至 _themes/）**：双轨制（自指"我"+演讲体）是杉井光特定风格，不是基底

### 坐标轴 5：关系网规模 = **5-8 角色小群体**

| 维度 | 约束 |
|------|------|
| 关系网规模 | 5-8 角色（小群体为主）|
| 互动模式 | 中心辐射（男主中心或女主中心）|
| 频次分布 | 均匀为主 |

**反例**（违反 = 不属于日轻）：100+ 角色群英会、4 梯队分布、多势力 6+ 阵营
**主题相关项（应移至 _themes/）**：8+ 女主群像、4 梯队、5 NEET+1 普通人 等是主题层

### 坐标轴 6：高潮模式 = **小光谱+角色选择型**

| 维度 | 约束 |
|------|------|
| 高潮光谱 | 小光谱（单章或单场景决胜）|
| 高潮类型 | 角色选择型（主角做自爆/封手/承认式选择）|
| 收束模式 | 自嘲余韵或群像收尾 |

**反例**（违反 = 不属于日轻）：跨卷多线汇集高潮、信息揭露型高潮、系统结算型高潮
**主题相关项（应移至 _themes/）**：Kingmaker/死循环/封手/会议决胜/大赛决胜 是主题层桥段

### 坐标轴 7：世界观密度 = **极简**

| 维度 | 约束 |
|------|------|
| 世界规则密度 | 极低（无超自然/科幻/玄幻/系统设定）|
| 设定层次 | 极简（仅真实世界）|

**反例**（违反 = 不属于日轻）：多层深渊世界、多文明硬规则、复杂系统设定
**主题相关项（应移至 _themes/）**：桌游/物质/概率/推理/末日意象/克苏鲁/维多利亚/系统 等"领域装置"是主题层

## 二、基底 vs 主题 vs 风格边界（关键正交性）

| 项 | 本基底（坐标轴）| 主题层（`_themes/`）| 风格层（`_styles/`）|
|---|----------|----------|----------|
| **POV 维度** | 第一人称（基底层）| — | 叙述态度（自嘲/吐槽/抒情/冷峻）= 风格 |
| **推进单位** | 关系-对话驱动（基底层）| "领域装置"（桌游/电玩/委托/推理）= 主题 | — |
| **句法** | 短句+极短段（基底层范围）| — | 具体数字（13.5/16/22.4）= 风格 |
| **内心通道** | 自由间接引语为主（基底层）| — | 双轨制/叙述者抒情/系统插话 = 风格 |
| **关系网规模** | 5-8 角色（基底层）| 8+ 女主群像/4 梯队/多势力 = 主题 | 互动模式（中心辐射/启示见证）= 主题 |
| **高潮模式** | 小光谱+角色选择（基底层）| Kingmaker/死循环/信息揭露/启示 = 主题 | 三阶释放/启示式/系统结算 = 风格 |
| **世界观密度** | 极简（基底层）| 末日背景/科幻/奇幻/系统 = 主题 | — |
| **物理道具** | — | 物理小物（便当/卡牌/信物）= 主题 | — |
| **死亡模式** | — | 0/隐喻/物理 = 主题 | — |
| **域词白名单** | — | 领域术语（桌游/末日/系统）= 主题 | 作家自反词（葵关南 IP 戏仿/远瞳自反词）= 风格 |
| **翻译腔** | — | — | 翻译版风格（启用见变体）|

**正交性原则**：基底、主题、风格三层**完全独立**——可任意子集叠加。

## 三、工程可加载参数（基底默认配置）

### sensory-writer style_profile（基底层默认）

```yaml
style_profile:
  profile_id: "japanese-light-novel-base-v1.2"
  type: "light-novel-base"
  # 7 坐标轴（基底层硬约束）
  narrative_voice:
    pov: "first-person"  # 坐标轴 1
  narrative_unit: "relation-dialogue-driven"  # 坐标轴 2
  language:
    avg_sentence_length: 13-25  # 坐标轴 3（范围）
    avg_paragraph_sentences: 1-3  # 坐标轴 3（范围）
    single_sentence_paragraph_pct: 30-70  # 坐标轴 3（范围）
  inner_channel:
    default: "free-indirect-speech"  # 坐标轴 4
    pct: 50  # 坐标轴 4（范围下限）
  ensemble_size: 5-8  # 坐标轴 5（范围）
  climax_type: "small-scope-character-choice"  # 坐标轴 6
  worldview: "minimal-realistic"  # 坐标轴 7
  # 不装任何主题/风格相关项
```

```yaml
§0 风格锚点:
```


## 四、与主题层 + 风格层的 5 维正交组合示例

### 示例 1：日轻基底 + 主题 school + 主题 tablegame + 风格 kuiguannan

- 基底提供 7 坐标轴（第一人称/关系驱动/短句+极短段/自由间接引语/5-8 角色/小光谱+角色选择/极简现实）

- 风格 kuiguannan 提供：自嘲叙述者（叙述态度）+ 葵关南式吐槽 + 跨作品戏仿 + 3 领域偏好

### 示例 2：日轻基底 + 主题 detective + 主题 supernatural + 主题 neet + 风格 shiniki

**实际效果**：

- 风格 shiniki 提供：双轨制内心通道（自指"我"+爱丽丝演讲体）+ 网络 NEET 语义场

## 五、与 chinese-webnovel-base-v1.2 的根本对照

| 坐标轴 | japanese-light-novel-base-v1.2 | chinese-webnovel-base-v1.2 |
|------|----------------------------|-------------------------|
| POV | 第一人称 | 多POV/第三人称 |
| 推进单位 | 关系-对话驱动（一次互动）| 事件驱动（一次大型事件）|
| 句法 | 短句+极短段（13-25 字 / 1-3 句）| 长句+中段（15-30 字 / 1-6 句）|
| 内心通道 | 自由间接引语为主 | 信息差机制（多模式）|
| 关系网规模 | 5-8 角色小群体 | 差异大 |
| 高潮模式 | 小光谱+角色选择 | 大型+信息揭露/启示/系统结算 三选一 |
| 世界观密度 | 极简 | 硬规则+多文明 |

**2 基底正交**：作者可"中国网文基底 + 日轻风格" = 实验风格（"中国网文事件驱动 + 日轻第一人称自嘲"）。

## 六、与主题层 + 风格层的加载协议

```
1. 加载基底层（japanese-light-novel-base-v1.2）：
   - 应用 7 坐标轴
   - 写入 author-voice.md 字段

2. 加载主题层（从 _themes/ 选择 1-N 个，可叠加）：
   - daily-life / romance / mystery / scifi-fantasy / doomsday / system / ensemble / cross-time
   - 例：["school", "romance"] = 校园+恋爱主题叠加

3. 加载风格层（从 _styles/ 选择 0-1 个）：
   - kuiguannan-style / amamorin-style / shiniki-style / yuantong-style / fengyue-style / buluofeng-style
   - 或 custom-author-style（作者自创）

4. 加载子变体层（从 _styles/ 选择 0-1 个）：
   - 嵌入风格层文件中

5. 应用约束检查：
   - 主题层不应违反基底层 7 坐标轴（违反时应警告）
   - 风格层不应违反基底层 7 坐标轴和已加载主题层（违反时应警告）
   - 子变体不应违反风格层和基底层
```
