# 日轻吐槽风格 v3.0（fallback 通用——不指定作者时回退此层）

> **fallback 定位**：当 `project-config.md` 指定**日轻基底 + 吐槽/自嘲/元叙事主题**但**不指定具体作者**时，加载本风格层作为通用模板。
> **指定作者**（如 `葵关南` / `雨森焚火` 等）时，sensory-writer 走作者档案（profiles/authors/）协议，**不加载本层**。

---

## 叙述态度

**自嘲式吐槽**：叙述者自称"路人/宅/小人物"，用自我贬抑压制对高光者的感情。出口想 X 说出来 Y——读者同时看到两层。

**元叙事自觉**：叙述者常插入"按轻小说规律……""按设定应该……"等元评论，把"我在写小说"变成叙事元素。

**轻小说腔**：长定语前置 + 被动语态残留 + 句末口语化 + ~波浪号作语气助词（如"我~很~累~"）。

**轻戏剧化**：吐槽归吐槽，核心仍是轻小说恋爱/关系/校园。

**翻译腔底色**：因日轻中文翻译版大量阅读基础，长定语+被动语态作常态语言纹理。

## 桥段选择

**会议式吐槽**（碧阳独有）：议题抛出 → 全员吐槽 → 会长"嗯哼"强行转话题 → 戳破关键信息 → "四面楚歌"密室感余韵

**桌游决胜**（葵关南桌游咖）：卡牌转交=情感信号 + 桌游-关系同构 + Kingmaker 决胜 + 物理小物作潜台词

**大赛决胜**（葵关南电玩咖）：邀请参赛 → 抽中强敌 → 0-3 落后 → 学对方定型句反击 → 拿下一局

**物理小物潜台词**（葵关南共性）：便当/卡牌/巧克力/印章/信物等小物承担场景的"潜台词"

**自爆型选择**（葵关南共性）：POV 角色在关键选择点做"自爆型"或"封手型"选择（如告白后转身走/放下卡牌）

## fallback 通用 vs 葵关南作者档案（人类参考）

- **葵关南作者档案**（profiles/authors/葵关南-默认.md v3.0）：含 POV 4 维 + 设计流程 3 阶段 + 风格选择指南——指定葵关南时加载
- **本 fallback 风格层**：只含叙述态度 + 域词 + 桥段——不指定作者时加载
- **关系**：作者档案替代本风格层（决策 7）；不指定作者时回退本层

## 失效模式（写作时避坑）

- ❌ 把 fallback 当作者档案用——✅ fallback 只是叙述态度/域词/桥段提示，不含 POV/设计流程
- ❌ 域词堆叠——✅ 域词应自然出现，不刻意炫
- ❌ 元叙事过度——✅ 元叙事应轻巧，不抢戏
- ❌ 会议式吐槽变成全员同意——✅ 会议=吐槽+辩论+全员同时发声
- ❌ 物理小物缺失——✅ 物理小物必填（潜台词载体）
