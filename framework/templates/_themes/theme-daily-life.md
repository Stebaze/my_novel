# 主题族：日常/校园/职场（theme-daily-life-v1）

> **核心定位**：本主题族装"日常/校园/职场"领域的题材内容——**不装基底坐标轴**（POV/推进/句法等），**不装作家风格**（自嘲/吐槽/双层信息差等）。
>
> **可叠加**：本主题可与基底（japanese-light-novel 或 chinese-webnovel）正交叠加，可与作家风格层（kuiguannan-style 等）独立叠加。

---

## 零、主题族包含

| 主题 | 描述 | 典型代表作品 |
|------|------|------------|
| **daily（日常）** | 日常生活/朋友/家庭/琐事 | 葵关南碧阳学园学生会、桌游咖 |
| **school（校园）** | 学校/学生/学园/学生会/同好会 | 葵关南碧阳、雨森焚火败犬女主 |
| **workplace（职场）** | 职场/工作/同事/上下级 | （示例：杉井光神之记事本中的拉面店）|

---

## 一、领域装置（必需）

日常/校园/职场主题族的"领域装置"是**校园/咖啡馆/办公室等真实场景**——**不引入**超自然/科幻/系统设定。

| 主题 | 领域装置 | 关键特征 |
|------|---------|--------|
| daily | 家庭/咖啡馆/拉面店/便利店 | 烟火气 |
| school | 学生会/教室/校园/同好会/社团室 | 封闭空间+多角色 |
| workplace | 办公室/会议室/店铺 | 同事/上下级 |

---

## 二、关系障碍（主题相关）

| 障碍类型 | 占比 | 主题相关 |
|---------|-----|---------|
| 误解/不直接表达 | ~30% | 日常/校园/职场共有 |
| 自我贬抑/不配得感 | ~25% | 校园/职场主角人设 |
| 身份/伪装 | ~15% | 校园/职场可有 |
| 外在（时间/距离）| ~15% | 校园毕业/职场调动 |
| 三角（被假身份挡住）| ~10% | 校园恋爱常见 |
| 不可达/命运式放弃 | ~5% | 极少见 |

## 九、5 维正交组合示例

### 示例 1：日轻基底 + 主题 daily + 风格 kuiguannan

```yaml
主风格档案: "japanese-light-novel-base-v1.2"
主题: ["daily"]
风格变体: ["kuiguannan-style-v1"]
```

**效果**：日轻 7 坐标轴 + 日常烟火气（家庭/拉面店/便利店）+ 葵关南自嘲吐槽。

### 示例 2：日轻基底 + 主题 school + 主题 romance + 风格 amamorin

```yaml
主风格档案: "japanese-light-novel-base-v1.2"
主题: ["school", "romance"]
风格变体: ["amamorin-style-v1"]
```

**效果**：日轻 7 坐标轴 + 校园场景（学生会/教室/同好会）+ 恋爱主题（8+ 女主/失败承认）+ 雨森焚火败犬揭示。

### 示例 3：日轻基底 + 主题 school + 主题 tablegame（叠加） + 风格 kuiguannan

```yaml
主风格档案: "japanese-light-novel-base-v1.2"
主题: ["school", "tablegame"]  # 校园+桌游叠加
风格变体: ["kuiguannan-style-v1"]
```

**效果**：日轻 7 坐标轴 + 校园场景 + 桌游域（区域占优/拖延策略/Kingmaker）+ 葵关南自嘲吐槽。

### 示例 4：中国网文基底 + 主题 school（实验性）

```yaml
主风格档案: "chinese-webnovel-base-v1.2"
主题: ["school"]
风格变体: []
```

**效果**：中国网文 7 坐标轴（多POV/事件驱动/长句+中段/...）+ 校园主题——实验性"中国网文事件驱动 + 校园日常"。

## 十、与其他主题族的边界

| 主题族 | 与本主题族的差异 |
|------|----------|
| romance（恋爱/后宫/败犬）| 恋爱主题关注"情感关系推进"——日常/校园/职场是"场景" |
| mystery（推理/侦探/超自然）| 推理主题有"必死的日常"——日常主题无死亡 |
| scifi-fantasy（科幻/奇幻/玄幻）| 科幻主题有"硬规则+多文明"——日常主题极简现实 |
| doomsday（末日/启示/仪式）| 末日主题有"末日背景+启示式高潮"——日常主题无 |
| system（系统/模拟/升级）| 系统主题有"系统推进"——日常主题无 |
| ensemble（群像/跨种族/多文明）| 群像主题规模 100+——日常主题 3-8 角色 |
| cross-time（穿越/重生/反英雄）| 穿越主题有"穿越机制"——日常主题无 |
