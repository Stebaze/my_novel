# 主题族：末日/启示/仪式（theme-doomsday-v1）

> **核心定位**：本主题族装"末日/启示/仪式/启示后"领域的题材内容——**不装基底坐标轴**，**不装作家风格**。
>
> **可叠加**：可与基底正交叠加（**通常应叠加 chinese-webnovel-base**——日轻基底不适用硬规则+多文明）。

---

## 零、主题族包含

| 主题 | 描述 | 典型代表作品 |
|------|------|------------|
| **doomsday（末日）** | 末日灾难/生存/文明崩溃 | 风月天启预报、不落风（部分）|
| **revelation（启示）** | 启示/认知翻转/真相揭示 | 风月天启预报 |
| **ritual（仪式）** | 仪式/殉道/遗志/传承 | 风月天启预报、不落风 |
| **apocalypse（启示录）** | 末日启示录风格 | 风月天启预报 |
| **post-civilization（启示后）** | 文明崩溃后/新文明/重建 | 风月天启预报（尾声新世历 471 年）|

## 九、5 维正交组合示例

### 示例 1：中国网文基底 + 主题 doomsday + 主题 revelation + 主题 ensemble + 风格 fengyue

```yaml
主风格档案: "chinese-webnovel-base-v1.2"
主题: ["doomsday", "revelation", "ensemble"]
风格变体: ["fengyue-style-v1"]
```

**效果**：中国网文 7 坐标轴 + 末日+启示+群像主题 + 风月叙述者抒情+棋局-传承意象闭环。

### 示例 2：中国网文基底 + 主题 ritual + 主题 apocalypse + 风格 fengyue

```yaml
主风格档案: "chinese-webnovel-base-v1.2"
主题: ["ritual", "apocalypse"]
风格变体: ["fengyue-style-v1"]
```

**效果**：中国网文 7 坐标轴 + 仪式+启示录主题 + 风月末日意象网络。

### 示例 3：中国网文基底 + 主题 post-civilization（实验性）

```yaml
主风格档案: "chinese-webnovel-base-v1.2"
主题: ["post-civilization"]
风格变体: []
```

**效果**：中国网文 7 坐标轴 + 启示后主题——实验性。

## 十、与其他主题族的边界

| 主题族 | 与本主题族的差异 |
|------|----------|
| daily-life（日常/校园/职场）| 日常无末日——本主题族有末日背景 |
| romance（恋爱/后宫/败犬）| 恋爱无末日——本主题族有 |
| mystery（推理/侦探/超自然）| 推理是日常+微超自然——本主题族是末日背景+启示 |
| scifi-fantasy（科幻/奇幻/玄幻）| 科幻是"未末日"——本主题族是"已末日/将末日" |
| system（系统/模拟/升级）| 系统无末日背景——本主题族有 |
| ensemble（群像/跨种族/多文明）| 群像是"关系规模"——本主题族是"题材" |
| cross-time（穿越/重生/反英雄）| 穿越是"穿越机制"——本主题族是"末日背景" |
