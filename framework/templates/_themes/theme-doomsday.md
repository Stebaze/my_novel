# 主题族：末日/启示/仪式 v2.0

> 本主题族装"末日/启示/仪式"领域的题材内容——**5 字段只装领域内容**，**不装基底坐标轴**，**不装作家风格**。
>
> **可叠加**：可与基底正交叠加，可与作家风格层独立叠加。**与 ensemble 主题族常叠加**（末日+多势力）。

## 领域装置

| 主题 | 领域装置 | 关键特征 |
|------|---------|---------|
| doomsday | 末日背景+持续灾难 | 持续状态 |
| revelation | 启示/认知翻转 | 读者理解改变 |
| ritual | 仪式/继承/传承 | 仪式感 |
| apocalypse | 末日决战/文明崩溃 | 终极事件 |
| post-civilization | 文明废墟/余烬 | 末世之后 |

**领域装置 = 场景的"题材空间"**——读者从这个空间里知道这是末日/启示/仪式故事

## 关系

### who（角色类型）

- **doomsday**：幸存者+继承者+前代（5-10 角色）
- **revelation**：观察者+行动者+先知（5-10 角色）
- **ritual**：继承者+已逝前辈+见证者（3-8 角色）
- **apocalypse**：多势力 A+B+锚点（5-15 角色）
- **post-civilization**：幸存者+变异体+AI/古神（5-10 角色）

### 障碍（关系冲突源）

| 障碍 | 主题相关 |
|------|---------|
| 末日灾难身份 | doomsday 强——角色因末日获得特殊身份/责任 |
| 认知理念分歧 | revelation 强——对末日的不同理解导致冲突 |
| 过去现在纠缠 | ritual 强——过去的决定影响现在 |
| 继承责任 | ritual/doomsday 强——继承者的负担 |
| 文明存亡 | apocalypse 强——终极问题 |
| 余烬重建 | post-civilization 强——废墟中的生存 |

## 高潮模式

| 主题 | 高潮类型 | 收束模式 |
|------|---------|---------|
| doomsday | 启示式+认知翻转 | 意象回响+元叙事收束 |
| revelation | 启示式+认知翻转 | 读者理解改变+元叙事 |
| ritual | 启示式+角色选择型 | 仪式完成+继承责任 |
| apocalypse | 信息揭露型+启示式 | 决战+文明存亡 |
| post-civilization | 启示式+角色选择型 | 余烬重建+生存选择 |

**高潮模式 = "末日/仪式推进到顶点的形态"**——读者期待的"那一下"是哪种

**高潮发生位置**：
- 启示式——在卷级末尾，读者对世界理解改变
- 认知翻转——在一次末日仪式末尾，角色或读者对世界理解改变
- 元叙事收束——记录者采访/历史时间跳跃作收束
- 仪式完成——在一次仪式末尾，传承完成

## 失效模式（写作时避坑）

- ❌ 把"领域装置"写成抽象名词——✅ 写具体可感的物（末日场景+城市废墟+仪式现场）
- ❌ 把"障碍"写成"内心冲突"——✅ 写可观察的具体事件（末日灾难/继承责任/文明存亡）
- ❌ 把"高潮模式"写成"情绪爆发"——✅ 写具体动作（仪式完成/启示揭示/决战）
- ❌ doomsday 主题写成"末日结束了"——✅ doomsday 是持续状态（背景而非事件）
- ❌ ritual 主题无仪式元素——✅ ritual 必须有仪式/传承/见证
- ❌ apocalypse 主题无终极事件——✅ apocalypse 必须有决战/文明崩溃
