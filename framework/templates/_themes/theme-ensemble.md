# 主题族：群像/跨种族/多文明/多势力/政治/史诗 v2.0

> 本主题族装"群像/跨种族/多文明/多势力/政治/史诗"领域的题材内容——**5 字段只装领域内容**，**不装基底坐标轴**，**不装作家风格**。
>
> **可叠加**：可与基底正交叠加，可与作家风格层独立叠加。**与 scifi-fantasy/doomsday/cross-time 主题族常叠加**。

## 领域装置

| 主题 | 领域装置 | 关键特征 |
|------|---------|---------|
| ensemble | 多角色群像 | 群像机制 |
| cross-species | 跨种族/异种族 | 文化差异+翻译梗 |
| multi-civilization | 多文明共存 | 文明级冲突 |
| multi-faction | 多势力博弈 | 政治格局 |
| political-intrigue | 政治阴谋/权谋 | 宫廷/议会/政府 |
| epic | 史诗/编年史/长河 | 跨年代叙事 |

**领域装置 = 场景的"题材空间"**——读者从这个空间里知道这是群像/政治/史诗故事

---

## 关系

### who（角色类型）

- **ensemble**：多角色（10-30 角色——多梯队）
- **cross-species**：人类+异种族（5-15 角色）
- **multi-civilization**：多文明角色代表（10-30 角色）
- **multi-faction**：多势力代表（10-20 角色）
- **political-intrigue**：政治角色+阴谋者（5-15 角色）
- **epic**：跨年代多角色（20-50 角色——编年史级）

### 障碍（关系冲突源）

| 障碍 | 主题相关 |
|------|---------|
| 跨种族/跨文化差异 | cross-species 强 |
| 文明级冲突 | multi-civilization 强 |
| 政治博弈 | multi-faction/political-intrigue 强 |
| 制度规则冲突 | multi-civilization 强 |
| 信息不对称（多角色知道不同真相）| ensemble 强 |
| 历史/时间跨度 | epic 强 |

## 常去的地方

| 主题 | 场景 | 特征 |
|------|------|------|
| ensemble | 多场景拼接（每章 2-4 场景）| 群像空间 |
| cross-species | 异种族地点+文化交流点 | 异种族空间 |
| multi-civilization | 多文明交界处+大使馆 | 文明空间 |
| multi-faction | 议会/战场/外交现场 | 政治空间 |
| political-intrigue | 宫廷/密室/会议室 | 阴谋空间 |
| epic | 跨年代多地点 | 编年史空间 |

**常去的地方 = 关系反复出现的"空间锚点"**——读者通过重复空间认知关系

---

## 推进单位

| 主题 | 推进单位 | 跨章衔接 |
|------|---------|---------|
| ensemble | 一次群像事件（多角色互动）| 群像延续+多线交叉 |
| cross-species | 一次跨种族互动+一次文化冲突 | 跨种族延续 |
| multi-civilization | 一次文明级事件+一次外交 | 文明延续 |
| multi-faction | 一次势力博弈+一次政治事件 | 势力延续 |
| political-intrigue | 一次阴谋+一次权谋 | 阴谋延续 |
| epic | 一次历史事件+一次跨年代 | 史诗延续 |

**推进单位 = "一章至少完成一次什么"**——明确读者读完一章能拿到的最小群像/政治推进

---

## 高潮模式

| 主题 | 高潮类型 | 收束模式 |
|------|---------|---------|
| ensemble | 信息揭露型/三阶释放 | 群像胜利+三阶释放 |
| cross-species | 信息揭露型/角色选择型 | 跨种族理解+选择 |
| multi-civilization | 信息揭露型/启示式 | 文明真相+启示 |
| multi-faction | 信息揭露型/启示式 | 势力真相+启示 |
| political-intrigue | 信息揭露型/启示式 | 阴谋真相+政治格局改变 |
| epic | 启示式/认知翻转 | 史诗+历史时间跳跃+元叙事收束 |

**高潮模式 = "群像/政治推进到顶点的形态"**——读者期待的"那一下"是哪种

**高潮发生位置**：
- 信息揭露型——在一次群像事件末尾，真相被揭示
- 三阶释放——在卷级末尾（认知释放+权力释放+视觉释放）
- 启示式——在卷级末尾，读者对世界理解改变
- 元叙事收束——记录者采访/历史时间跳跃

## 失效模式（写作时避坑）

- ❌ 把"领域装置"写成抽象名词——✅ 写具体可感的物（多场景拼接+议会+跨种族地点）
- ❌ 把"障碍"写成"内心冲突"——✅ 写可观察的具体事件（跨种族/文明级冲突/政治博弈）
- ❌ 把"高潮模式"写成"情绪爆发"——✅ 写具体动作（信息揭露/三阶释放/启示）
- ❌ ensemble 主题单角色视角——✅ ensemble 必须多角色+多线交叉
- ❌ political-intrigue 主题无阴谋元素——✅ political-intrigue 必须有阴谋/权谋
- ❌ epic 主题无跨年代——✅ epic 必须有跨年代/编年史级叙事
