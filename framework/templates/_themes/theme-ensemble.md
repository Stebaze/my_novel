# 主题族：群像/跨种族/多文明（theme-ensemble-v1）

> **核心定位**：本主题族装"群像/跨种族/多文明/多势力/政治/史诗"领域的题材内容——**不装基底坐标轴**，**不装作家风格**。
>
> **可叠加**：可与基底正交叠加（**通常应叠加 chinese-webnovel-base**——日轻基底不适用 100+ 角色群英会）。

---

## 零、主题族包含

| 主题 | 描述 | 典型代表作品 |
|------|------|------------|
| **ensemble（群像）** | 多角色/等权重/4 梯队 | 远瞳深海余烬、黎明之剑 |
| **cross-species（跨种族）** | 神/魔/精灵/矮人/兽/异种族 | 远瞳黎明之剑、不落风 |
| **multi-civilization（多文明）** | 多文明/多国家/多势力 | 远瞳黎明之剑 |
| **multi-faction（多势力）** | 多个对立阵营 | 风月天启预报、不落风 |
| **political-intrigue（政治权谋）** | 派系/阴谋/博弈 | 远瞳黎明之剑、异常生物见闻录 |
| **epic（史诗）** | 大时代/大世界/跨卷 | 远瞳、风月 |

## 九、5 维正交组合示例

### 示例 1：中国网文基底 + 主题 ensemble + 主题 multi-civilization + 主题 scifi + 主题 cosmic-horror + 风格 yuantong

```yaml
主风格档案: "chinese-webnovel-base-v1.2"
主题: ["ensemble", "multi-civilization", "scifi", "cosmic-horror"]  # 4 主题叠加
风格变体: ["yuantong-style-v1"]
```

**效果**：中国网文 7 坐标轴 + 群像+多文明+科幻+克苏鲁主题 + 远瞳三阶释放高潮。

### 示例 2：中国网文基底 + 主题 multi-faction + 主题 doomsday + 主题 revelation + 风格 fengyue

```yaml
主风格档案: "chinese-webnovel-base-v1.2"
主题: ["multi-faction", "doomsday", "revelation"]
风格变体: ["fengyue-style-v1"]
```

**效果**：中国网文 7 坐标轴 + 多势力+末日+启示主题 + 风月叙述者抒情+棋局-传承闭环。

### 示例 3：中国网文基底 + 主题 ensemble + 主题 cross-species + 主题 political-intrigue + 风格 custom-author-style

```yaml
主风格档案: "chinese-webnovel-base-v1.2"
主题: ["ensemble", "cross-species", "political-intrigue"]
风格变体: ["custom-author-style"]
```

**效果**：中国网文 7 坐标轴 + 群像+跨种族+政治权谋主题 + 作者自创风格。

### 示例 4：日轻基底 + 主题 ensemble（实验性，应警告）

```yaml
主风格档案: "japanese-light-novel-base-v1.2"
主题: ["ensemble"]  # 群像主题与日轻基底冲突（100+ 角色）
风格变体: []
```

**效果**：日轻 7 坐标轴（5-8 角色小群体） + 群像主题（10-30 角色）——**违反基底层坐标轴 5**——工程应警告。

## 十、与其他主题族的边界

| 主题族 | 与本主题族的差异 |
|------|----------|
| daily-life（日常/校园/职场）| 日常 3-8 角色——本主题族 10-100 角色 |
| romance（恋爱/后宫/败犬）| 恋爱 2-10 角色——本主题族 10+ 角色 |
| mystery（推理/侦探/超自然）| 推理 5-10 角色——本主题族 10+ |
| scifi-fantasy（科幻/奇幻/玄幻）| 科幻是"题材"——本主题族是"关系规模"（可叠加）|
| doomsday（末日/启示/仪式）| 末日是"题材"——本主题族是"关系规模"（可叠加）|
| system（系统/模拟/升级）| 系统是"题材"——本主题族是"关系规模"（可叠加）|
| cross-time（穿越/重生/反英雄）| 穿越是"穿越机制"——本主题族是"关系规模"（可叠加）|
