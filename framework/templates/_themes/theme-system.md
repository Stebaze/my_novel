# 主题族：系统/模拟/升级（theme-system-v1）

> **核心定位**：本主题族装"系统/模拟/升级/游戏/都市奇幻"领域的题材内容——**不装基底坐标轴**，**不装作家风格**。
>
> **可叠加**：可与基底正交叠加（**通常应叠加 chinese-webnovel-base**——日轻基底不适用硬规则+系统）。

---

## 零、主题族包含

| 主题 | 描述 | 典型代表作品 |
|------|------|------------|
| **system（系统）** | 系统流/金手指/系统提示 | 不落风魔女小姐的速通手册 |
| **simulator（模拟）** | 模拟器/单次模拟/24h 倒计时 | 不落风魔女小姐的速通手册 |
| **level-up（升级）** | 升级流/技能树/点数 | 不落风 |
| **game（游戏）** | 游戏/攻略/升级 | 异世界日轻常见 |
| **achievement（成就）** | 成就/任务/奖励 | 系统流常见 |
| **urban-fantasy（都市奇幻）** | 都市背景+奇幻元素 | 维多利亚+系统 |

## 九、5 维正交组合示例

### 示例 1：中国网文基底 + 主题 system + 主题 simulator + 主题 urban-fantasy + 主题 cross-time + 主题 anti-hero + 风格 buluofeng

```yaml
主风格档案: "chinese-webnovel-base-v1.2"
主题: ["system", "simulator", "urban-fantasy", "cross-time", "anti-hero"]  # 5 主题叠加
风格变体: ["buluofeng-style-v1"]
```

**效果**：中国网文 7 坐标轴 + 系统+模拟+都市奇幻+穿越+反英雄主题（不落风 5 主题全加载）+ 不落风系统作为第二叙事声音。

### 示例 2：中国网文基底 + 主题 level-up + 主题 game + 主题 ensemble

```yaml
主风格档案: "chinese-webnovel-base-v1.2"
主题: ["level-up", "game", "ensemble"]
风格变体: ["custom-author-style"]
```

**效果**：中国网文 7 坐标轴 + 升级+游戏+群像主题 + 作者自创风格。

### 示例 3：日轻基底 + 主题 game（实验性，应警告）

```yaml
主风格档案: "japanese-light-novel-base-v1.2"
主题: ["game"]  # 游戏主题与日轻基底冲突（硬规则+系统）
风格变体: []
```

**效果**：日轻 7 坐标轴（极简现实） + 游戏主题（硬规则+系统）——**违反基底层坐标轴 7**——工程应警告。

## 十、与其他主题族的边界

| 主题族 | 与本主题族的差异 |
|------|----------|
| daily-life（日常/校园/职场）| 日常无系统——本主题族有系统作为叙事声音 |
| romance（恋爱/后宫/败犬）| 恋爱无系统——本主题族有 |
| mystery（推理/侦探/超自然）| 推理是日常+微超自然——本主题族是硬规则+系统 |
| scifi-fantasy（科幻/奇幻/玄幻）| 科幻是"未末日"或"无系统"——本主题族是系统驱动 |
| doomsday（末日/启示/仪式）| 末日是"末日背景"——本主题族是"系统"（与末日正交可叠加）|
| ensemble（群像/跨种族/多文明）| 群像是"关系规模"——本主题族是"题材" |
| cross-time（穿越/重生/反英雄）| 穿越是"穿越机制"——本主题族是"系统"（与穿越正交可叠加）|
