# 主题族：穿越/重生/反英雄/转生/异世界/回归 v2.0

> 本主题族装"穿越/重生/反英雄/转生/异世界/回归"领域的题材内容——**5 字段只装领域内容**，**不装基底坐标轴**，**不装作家风格**。
>
> **可叠加**：可与基底正交叠加，可与作家风格层独立叠加。**与 system/scifi-fantasy/romance 主题族常叠加**。

## 领域装置

| 主题 | 领域装置 | 关键特征 |
|------|---------|---------|

## 关系

### who（角色类型）

- **cross-time**：跨时间角色（5-10 角色）
- **rebirth**：重生者+前世/今生角色（3-8 角色）
- **anti-hero**：反英雄主角+对手+伙伴（3-5 角色）
- **transmigration**：原主+穿越者+原关系网（5-10 角色）
- **isekai**：穿越者+原住民+系统（3-10 角色）
- **regression**：回归者+当前时间角色（3-8 角色）

### 障碍（关系冲突源）

| 障碍 | 主题相关 |
|------|---------|
| 因果悖论 | cross-time/rebirth/regression 强 |
| 命运不可逆 | cross-time 强 |
| 知识限制（前世知识有边界）| rebirth/regression 强 |
| 道德困境（反英雄）| anti-hero 强 |
| 原主/穿越者身份冲突 | transmigration 强 |
| 异世界规则差异 | isekai 强 |
| 回归后的责任 | regression 强 |

## 推进单位

| 主题 | 推进单位 | 跨章衔接 |
|------|---------|---------|
| cross-time | 一次跨时间事件+一次因果揭示 | 时间线延续 |
| rebirth | 一次重生+一次改变前世轨迹 | 重生延续+命运推进 |
| anti-hero | 一次反英雄行动+一次道德困境 | 行动延续+道德抉择 |

| isekai | 一次异世界事件+一次系统结算 | 异世界延续 |

**推进单位 = "一章至少完成一次什么"**——明确读者读完一章能拿到的最小穿越/重生推进

## 高潮模式

| 主题 | 高潮类型 | 收束模式 |
|------|---------|---------|
| cross-time | 信息揭露型/角色选择型 | 因果真相+角色选择 |
| rebirth | 信息揭露型/角色选择型 | 前世真相+改变命运 |
| anti-hero | 角色选择型 | 道德抉择+反英雄胜利 |
| transmigration | 信息揭露型/角色选择型 | 身份真相+选择 |
| isekai | 信息揭露型/系统结算型 | 异世界真相+系统结算 |
| regression | 信息揭露型/角色选择型 | 回归真相+选择 |

**高潮模式 = "穿越/重生推进到顶点的形态"**——读者期待的"那一下"是哪种

**高潮发生位置**：
- 信息揭露型——在一次穿越/重生事件末尾，真相被揭示
- 角色选择型——在一次道德困境末尾，POV 角色做反英雄选择
- 系统结算型——在一次异世界事件末尾，系统评价+奖励
- 改变命运——在一次重生事件末尾，POV 角色成功改变前世轨迹

## 边界（与其他主题族）

| 主题族 | 与本主题族的差异 |
|------|----------|
| scifi-fantasy | 科幻/奇幻是"具体世界"——本主题族是"时间穿越" |
| system | 系统主题是"游戏机制"——本主题族是"穿越/重生" |
| romance | romance 是"情感"——本主题族是"身份+时间" |

## 失效模式（写作时避坑）

- ❌ 把"领域装置"写成抽象名词——✅ 写具体可感的物（前世/今生/异世界/系统）
- ❌ 把"障碍"写成"内心冲突"——✅ 写可观察的具体事件（因果悖论/命运不可逆/道德困境）
- ❌ 把"高潮模式"写成"情绪爆发"——✅ 写具体动作（真相揭示/改变命运/道德抉择）
- ❌ rebirth 主题直接给金手指——✅ rebirth 应有知识限制+道德负担
- ❌ anti-hero 主题变爽文——✅ anti-hero 必须有道德困境
- ❌ transmigration 主题忽略原主——✅ transmigration 必须有原主/穿越者身份冲突
