# 主题族：穿越/重生/反英雄（theme-cross-time-v1）

> **核心定位**：本主题族装"穿越/重生/反英雄/转生/异世界/回归"领域的题材内容——**不装基底坐标轴**，**不装作家风格**。
>
> **可叠加**：可与基底正交叠加（**通常应叠加 chinese-webnovel-base**——日轻基底不适用硬规则+反英雄）。

---

## 零、主题族包含

| 主题 | 描述 | 典型代表作品 |
|------|------|------------|
| **cross-time（穿越）** | 穿越到过去/未来/异世界 | 不落风魔女小姐的速通手册 |
| **rebirth（重生）** | 重生回到过去/未来 | （典型网文亚类）|
| **anti-hero（反英雄）** | 反英雄主角/无金手指预备知识 | 不落风 |
| **transmigration（转生）** | 转生到异世界/另一身体 | （典型日轻/网文）|
| **isekai（异世界）** | 异世界穿越 | （典型日轻）|
| **regression（回归）** | 重新开始/记忆保留 | （典型网文）|

## 九、5 维正交组合示例

### 示例 1：中国网文基底 + 主题 cross-time + 主题 anti-hero + 主题 system + 主题 simulator + 主题 urban-fantasy + 风格 buluofeng

```yaml
主风格档案: "chinese-webnovel-base-v1.2"
主题: ["cross-time", "anti-hero", "system", "simulator", "urban-fantasy"]  # 5 主题叠加
风格变体: ["buluofeng-style-v1"]
```

**效果**：中国网文 7 坐标轴 + 穿越+反英雄+系统+模拟+都市奇幻主题（不落风 5 主题全加载）+ 不落风系统作为第二叙事声音。

### 示例 2：中国网文基底 + 主题 rebirth + 主题 multi-civilization + 主题 ensemble

```yaml
主风格档案: "chinese-webnovel-base-v1.2"
主题: ["rebirth", "multi-civilization", "ensemble"]
风格变体: ["custom-author-style"]
```

**效果**：中国网文 7 坐标轴 + 重生+多文明+群像主题 + 作者自创风格。

### 示例 3：日轻基底 + 主题 isekai（实验性，应警告）

```yaml
主风格档案: "japanese-light-novel-base-v1.2"
主题: ["isekai"]  # 异世界主题与日轻基底冲突（硬规则+多文明）
风格变体: []
```

**效果**：日轻 7 坐标轴（极简现实） + 异世界主题（硬规则+多文明）——**违反基底层坐标轴 7**——工程应警告（但日轻 isekai 是常见亚类，可能接受）。

### 示例 4：日轻基底 + 主题 cross-time + 主题 romance + 主题 school（实验性，混合）

```yaml
主风格档案: "japanese-light-novel-base-v1.2"
主题: ["cross-time", "romance", "school"]
风格变体: ["custom-author-style"]
```

**效果**：日轻 7 坐标轴 + 穿越+恋爱+校园主题（混合）——实验性"日轻校园+穿越+恋爱"。

## 十、与其他主题族的边界

| 主题族 | 与本主题族的差异 |
|------|----------|
| daily-life（日常/校园/职场）| 日常无穿越——本主题族有穿越机制 |
| romance（恋爱/后宫/败犬）| 恋爱无穿越——本主题族有 |
| mystery（推理/侦探/超自然）| 推理是日常+微超自然——本主题族是穿越 |
| scifi-fantasy（科幻/奇幻/玄幻）| 科幻无穿越——本主题族有（可叠加）|
| doomsday（末日/启示/仪式）| 末日无穿越——本主题族有（可叠加）|
| system（系统/模拟/升级）| 系统是"题材"——本主题族是"穿越机制"（可叠加）|
| ensemble（群像/跨种族/多文明）| 群像是"关系规模"——本主题族是"穿越机制"（可叠加）|
