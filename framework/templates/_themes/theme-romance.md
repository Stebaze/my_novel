# 主题族：恋爱/后宫/败犬（theme-romance-v1）

> **核心定位**：本主题族装"恋爱/后宫/败犬"领域的题材内容——**不装基底坐标轴**，**不装作家风格**。
>
> **可叠加**：可与基底正交叠加，可与作家风格层独立叠加。

---

## 零、主题族包含

| 主题 | 描述 | 典型代表作品 |
|------|------|------------|
| **romance（恋爱）** | 1v1 恋爱为主，少女主 | 葵关南桌游咖、碧阳 |
| **harem（后宫）** | 多女主围绕男主 | 葵关南碧阳、桌游咖 |
| **loser-romance（败犬）** | 多女主"单恋落败" | 雨森焚火败犬女主 |
| **school-romance（校园恋爱）** | 校园+恋爱 | 雨森焚火败犬女主、葵关南碧阳 |

---

## 一、领域装置（必需）

| 主题 | 领域装置 | 关键特征 |
|------|---------|--------|
| romance | 约会/咖啡馆/教室 | 1v1 关系 |
| harem | 学生会/同好会/工作场所 | 多女主集中场景 |
| loser-romance | 教室/食堂/学校走廊 | 校园日常 |
| school-romance | 教室/学校活动 | 校园 |

---

## 二、关系障碍（主题相关）

| 障碍类型 | 占比 | 主题相关 |
|---------|-----|---------|
| 不可达/命运式放弃 | ~25% | loser-romance 强（烧盐/朝云式主动放弃）|
| 身份差距（师生/学姊/转学生）| ~20% | harem/loser-romance |
| 自我欺骗/不直接表达 | ~20% | romance/harem 强 |
| 三角（被假身份挡住）| ~15% | harem/romance |
| 误解/不直接表达 | ~15% | romance |
| 外在（时间/距离）| ~5% | school-romance |

---

## 三、关系网规模

| 主题 | 规模 | 互动模式 |
|------|------|---------|
| romance | 2-5 角色 | 1v1 中心辐射 |
| harem | 5-10 角色 | 男主中心+多女主 |
| loser-romance | **8+ 角色**（焦点轮换）| 多女主焦点轮换+温水不可触碰 |
| school-romance | 5-10 角色 | 男主中心+多女主 |

---

## 四、推进单位

| 主题 | 推进单位 | 跨章衔接 |
|------|---------|--------|
| romance | 一次互动（含物理小物）| 物理小物转交 |
| harem | 一次互动（含物理小物+角色事件）| 多女主焦点轮换 |
| loser-romance | **一次败的揭示**（5 步结构）| 物理小物转交+败犬焦点轮换 |
| school-romance | 一次互动（含物理小物）| 校园场景转换 |

## 五、高潮模式

## 九、5 维正交组合示例

### 示例 1：日轻基底 + 主题 romance + 主题 school + 风格 amamorin

```yaml
主风格档案: "japanese-light-novel-base-v1.2"
主题: ["romance", "school"]
风格变体: ["amamorin-style-v1"]
```

**效果**：日轻 7 坐标轴 + 校园恋爱主题 + 雨森焚火败犬揭示 5 步结构。

### 示例 2：日轻基底 + 主题 loser-romance + 主题 harem（叠加）+ 风格 amamorin

```yaml
主风格档案: "japanese-light-novel-base-v1.2"
主题: ["loser-romance", "harem"]
风格变体: ["amamorin-style-v1"]
```

**效果**：日轻 7 坐标轴 + 败犬多女主+后宫+失败承认式高潮 + 雨森焚火败犬揭示 5 步结构。

### 示例 3：日轻基底 + 主题 romance + 主题 tablegame + 风格 kuiguannan

```yaml

```

**效果**：日轻 7 坐标轴 + 恋爱+桌游+物理小物转交 + 葵关南桌游-关系同构机制。

### 示例 4：中国网文基底 + 主题 romance（实验性）

**效果**：中国网文 7 坐标轴（多POV/事件驱动/...）+ 恋爱主题——实验性"中国网文事件驱动 + 恋爱"。

## 十、与其他主题族的边界

| 主题族 | 与本主题族的差异 |
|------|----------|
| daily-life（日常/校园/职场）| 日常/校园是"场景"——本主题族是"关系" |
| mystery（推理/侦探/超自然）| 推理主题关注"谜题推进"——本主题族关注"情感推进" |
| scifi-fantasy（科幻/奇幻/玄幻）| 科幻主题有"硬规则"——本主题族通常极简 |
| doomsday（末日/启示/仪式）| 末日主题关注"生存"——本主题族关注"情感" |
| ensemble（群像/跨种族/多文明）| 群像主题规模 100+——本主题族 2-10 角色 |
