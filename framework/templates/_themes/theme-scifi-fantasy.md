# 主题族：科幻/奇幻/玄幻/异世界/克苏鲁/末世 v2.0

> 本主题族装"科幻/奇幻/玄幻/异世界/克苏鲁/末世"领域的题材内容——**5 字段只装领域内容**，**不装基底坐标轴**，**不装作家风格**。
>
> **可叠加**：可与基底正交叠加，可与作家风格层独立叠加。**与 ensemble 主题族常叠加**（多文明科幻群像）。
>
> **世界观揭露模式**：本主题族主要走"集中揭"（中国网文基底）/"边写边揭"（日轻基底）——硬规则需要集中或行动中揭。

## 领域装置

| 主题 | 领域装置 | 关键特征 |
|------|---------|---------|

**领域装置 = 场景的"题材空间"**——读者从这个空间里知道这是科幻/奇幻/末世故事

## 关系

### who（角色类型）

- **scifi**：人类+AI+异种族（5-15 角色）
- **fantasy**：人类+精灵+矮人+龙（5-15 角色）
- **xianxia**：人族+妖族+散仙（5-15 角色）
- **isekai**：穿越者+原住民+系统（3-10 角色）
- **cosmic-horror**：凡人+古神+半神（3-8 角色）
- **post-apocalyptic**：幸存者+变异体+AI（5-15 角色）

### 障碍（关系冲突源）

| 障碍 | 主题相关 |
|------|---------|
| 跨种族/跨文化差异 | scifi/fantasy/cosmic-horror 强 |
| 制度规则冲突 | scifi/fantasy/xianxia 强 |
| 信息不对称 | isekai/cosmic-horror 强 |
| 阶级/身份等级 | scifi/fantasy/xianxia 强 |
| 历史/时间跨度 | post-apocalyptic/cosmic-horror 强 |
| 古神/超自然力量 | cosmic-horror 强 |
| 末世生存 | post-apocalyptic 强 |

## 推进单位

| 主题 | 推进单位 | 跨章衔接 |
|------|---------|---------|
| scifi | 一次岛弧/一次战役/一次揭露 | 事件延续+信息释放漏斗形 |
| fantasy | 一次任务/一次冒险/一次战斗 | 任务延续+卷级推进 |
| xianxia | 一次修炼/一次突破/一次历练 | 修炼延续+境界推进 |
| isekai | 一次穿越事件/一次异世界互动 | 异世界延续 |
| cosmic-horror | 一次岛弧（公路片）/ 一次古神接触 | 岛弧延续+卷级主线 |
| post-apocalyptic | 一次末世事件/一次生存挑战 | 末世延续 |

**推进单位 = "一章至少完成一次什么"**——明确读者读完一章能拿到的最小事件推进

## 高潮模式

| 主题 | 高潮类型 | 收束模式 |
|------|---------|---------|
| scifi | 信息揭露型/启示式/系统结算型 | 三阶释放（认知+权力+视觉）|
| fantasy | 信息揭露型 | 真相揭示+战斗胜利 |
| xianxia | 信息揭露型 | 境界突破+战斗胜利 |
| isekai | 信息揭露型/系统结算型 | 异世界真相+系统结算 |
| cosmic-horror | 信息揭露型 | 古神真相+恐怖揭示 |
| post-apocalyptic | 信息揭露型/启示式 | 末世真相+启示 |

**高潮模式 = "事件推进到顶点的形态"**——读者期待的"那一下"是哪种

**高潮发生位置**：
- 信息揭露型——在一次岛弧末尾，真相被揭示（科幻+奇幻+修真）
- 启示式——在卷级末尾，读者对世界理解改变
- 系统结算型——在一次系统事件末尾，系统评价+奖励
- 恐怖揭示——在一次古神接触末尾，恐怖真相

## 边界（与其他主题族）

| 主题族 | 与本主题族的差异 |
|------|----------|
| mystery | 推理主题关注"谜题"——本主题族关注"世界设定" |
| doomsday | 末日主题是"持续状态"——本主题族是"具体末世场景" |
| system | 系统主题关注"游戏机制"——本主题族关注"硬规则/魔法" |

## 失效模式（写作时避坑）

- ❌ 把"领域装置"写成抽象名词——✅ 写具体可感的物（飞船/魔法学院/古神遗迹）
- ❌ 把"障碍"写成"内心冲突"——✅ 写可观察的具体事件（跨种族/制度冲突/古神接触）
- ❌ 把"高潮模式"写成"情绪爆发"——✅ 写具体动作（真相揭示/境界突破/战斗胜利）
- ❌ scifi 主题无硬规则——✅ scifi 必须有具体科技/工业设定
- ❌ cosmic-horror 主题直接写古神——✅ cosmic-horror 必须有"不可名状"+"信息差"+"污染"
- ❌ post-apocalyptic 主题无末世背景——✅ post-apocalyptic 必须有"末世持续状态"+"生存挑战"
