# 主题族：科幻/奇幻/玄幻/异世界/克苏鲁/末日后（theme-scifi-fantasy-v1）

> **核心定位**：本主题族装"科幻/奇幻/玄幻/异世界/克苏鲁/末日后"领域的题材内容——**不装基底坐标轴**，**不装作家风格**。
>
> **可叠加**：可与基底正交叠加（**通常应叠加 chinese-webnovel-base**——日轻基底不适用硬规则+多文明）。

---

## 零、主题族包含

| 主题 | 描述 | 典型代表作品 |
|------|------|------------|
| **scifi（科幻）** | 硬科幻/软科幻/星际/未来 | 远瞳深海余烬、黎明之剑 |
| **fantasy（奇幻）** | 西式奇幻/魔法/精灵/矮人 | 远瞳黎明之剑 |
| **xianxia（玄幻）** | 修真/灵气/法宝/境界 | （典型网文亚类）|
| **isekai（异世界）** | 穿越到异世界/重生/转生 | （典型日轻亚类）|
| **cosmic-horror（克苏鲁）** | 古神/深渊/不可名状 | 远瞳深海余烬 |
| **post-apocalyptic（末日后）** | 末日后的世界/重建 | （可与 doomsday 主题族叠加）|

## 九、5 维正交组合示例

### 示例 1：中国网文基底 + 主题 scifi + 主题 cosmic-horror + 主题 ensemble + 主题 multi-civilization（叠加）+ 风格 yuantong

```yaml
主风格档案: "chinese-webnovel-base-v1.2"
主题: ["scifi", "cosmic-horror", "ensemble", "multi-civilization"]  # 主题叠加
风格变体: ["yuantong-style-v1"]
```

**效果**：中国网文 7 坐标轴 + 科幻+克苏鲁+群像+多文明主题 + 远瞳三阶释放高潮。

### 示例 2：中国网文基底 + 主题 fantasy + 主题 xianxia（叠加）+ 主题 ensemble + 风格 custom-author-style

```yaml
主风格档案: "chinese-webnovel-base-v1.2"
主题: ["fantasy", "xianxia", "ensemble"]
风格变体: ["custom-author-style"]
```

**效果**：中国网文 7 坐标轴 + 西幻+修真+群像主题 + 作者自创风格。

### 示例 3：中国网文基底 + 主题 cosmic-horror + 风格 yuantong

```yaml
主风格档案: "chinese-webnovel-base-v1.2"
主题: ["cosmic-horror"]
风格变体: ["yuantong-style-v1"]
```

**效果**：中国网文 7 坐标轴 + 单纯克苏鲁主题 + 远瞳三阶释放。

### 示例 4：日轻基底 + 主题 isekai（实验性，应警告）

```yaml
主风格档案: "japanese-light-novel-base-v1.2"
主题: ["isekai"]  # 异世界主题与日轻基底冲突
风格变体: []
```

**效果**：日轻 7 坐标轴（极简现实） + 异世界主题（硬规则+多文明）——**违反基底层坐标轴 7**——工程应警告。

## 十、与其他主题族的边界

| 主题族 | 与本主题族的差异 |
|------|----------|
| daily-life（日常/校园/职场）| 日常无硬规则——本主题族有硬规则 |
| romance（恋爱/后宫/败犬）| 恋爱无末日/危机——本主题族有文明存续/末日 |
| mystery（推理/侦探/超自然）| 推理是日常现实+微超自然——本主题族是硬规则+多文明 |
| doomsday（末日/启示/仪式）| 末日是"末日背景"——本主题族是"未末日"或"末日后" |
| system（系统/模拟/升级）| 系统主题有"系统推进"——本主题族无系统 |
| ensemble（群像/跨种族/多文明）| 群像是"关系规模"——本主题族是"题材" |
| cross-time（穿越/重生/反英雄）| 穿越是"穿越机制"——本主题族是"题材" |
