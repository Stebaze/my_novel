# 作家档案工程值表（v5 修订——5 维正交化最终版）

> **v5 核心洞察（关键元层面）**：之前的分解（v3 4 维分层 / v4 4 维正交）**漏掉了"主题层"**——把"主题相关"项（桌游/学园/校园/推理/末日/科幻/系统/穿越/群像等）误归到"基底"或"风格"。v5 引入**5 维正交**：
>
> - **L0 体裁（genre）** = 顶层分类（轻小说 / 网文 / 严肃文学）
> - **L1 主题（theme）** = 题材域选择（**8 主题族，可叠加**）
> - **L2 基底（base）** = 跨主题跨体裁的句法骨架（**7 坐标轴，2 选 1**）
> - **L3 风格（style）** = 作者特定的叙述态度+域词+桥段选择（**6 作家风格层**）
> - **L4 子变体（subvariant）** = 单作品特定细粒度（嵌入风格层文件）
> - **L5 题材特化（specialization）** = 题材域白名单/特殊变体（按需）
>
> **5 维正交原则**：所有维度**完全独立**——可任意子集叠加。

## v5 vs v4 关键差异

| 维度 | v4 (4 维正交) | v5 (5 维正交) |
|------|----------|----------|
| 设计原则 | 4 维独立 + 可任意组合 | **5 维独立 + 可任意组合**（增加主题层）|
| 主题层 | **缺失**（混在基底/风格中）| **独立**——8 主题族文件 |
| 基底定义 | "跨主题通用"（但混入主题项）| **真正跨主题通用**——只装 7 跨主题坐标轴 |
| 风格定义 | 作者特定（含主题项）| **作者特定**——只装叙述态度+域词+桥段选择 |
| 主题叠加 | 不支持 | **支持**（如 `["scifi", "ensemble", "multi-civilization"]` 同时加载）|
| 工程文件 | 14 个 | **22 个**（增加 8 主题族）|

## 一、四维分层原则

工程把作家风格信息按 4 维分层，从"最跨作通用"到"最作家特定"：

| 层级 | 名称 | 性质 | 工程作用 | 加载机制 |
|------|------|------|---------|---------|
| **L1** | 网络原生共性 | 跨题材跨作家跨地区 | 工程默认基底 | 自动加载（不可关闭） |
| **L2** | 题材/世界观密度谱 | 跨作家（同题材可共享）| 题材特化基底 | `style_profile_type` 加载（如 light-novel / web-scifi / doomsday） |
| **L3** | 作家特定 | 单作家跨作品稳定特征 | 作家风格档案 | `style_profile_variant` 加载（kuiguannan-default / yuantong-default / fengyue-default） |
| **L4** | 单作品特定 | 单作特定（如桌游咖的桌游语义场）| 作品变体 | `style_profile_subvariant` 加载（kuiguannan-tablegame / yuantong-deep-abyss / fengyue-apocalypse） |

**分层判定规则**：
- **L1 标准**：在所有 3 个作家档案中都能找到稳定证据
- **L2 标准**：在 2 个及以上作家中能找到，或在 1 个作家中跨作品稳定
- **L3 标准**：仅在 1 个作家档案中有完整证据
- **L4 标准**：仅在 1 个作品的画像中有证据

## 二、L1 跨作通用：网络原生共性（自动加载）

> 这部分**应该自动加载到所有项目**——是中文网络小说原生写法的物理基础。

### L1.1 段长 1-3 句（极短段密度）

**证据**：
- 葵关南桌游咖 + 败犬女主：平均段落 1.3-2.9 句，极短段（1句）占 27-70%
- 远瞳深海：极短段（1-3 句）占主流
- 风月天启预报：极短段（1-3 句）占 99%

**工程约束**：
```yaml
avg_paragraph_sentences: 1.3-3.0
single_sentence_paragraph_pct: 30-70
```

**工程价值**：✅ 直接入库 sensory-writer `style_profile.language.paragraph` 字段作为硬约束。

### L1.2 领域浸入作为架构级原理

**证据**：
- 远瞳：克苏鲁+科学+地球梗（深海）/ 制度+魔导（黎明）/ 神系+多世界（异常）
- 葵关南：桌游（桌游咖）/ 物质/概率（败犬女主）
- 风月：末日意象（光暗/灰烬/棋局/深渊）

**跨作共性**：每个作家都有"用一个特定领域/意象作为主角认知框架"——这是**网文与严肃文学的根本差异**——严肃文学比喻源分散，网文比喻源单一（沉浸）。

**工程约束**：
```yaml
semantic_field:
  domain_immersion: "required"  # 必有一个领域浸入
  single_source_domain: true  # 比喻源领域单一
  domain_whitelist:  # 各题材的领域术语白名单
    web-scifi: ["克苏鲁", "古神", "深渊", "灵界", "大湮灭", ...]
    web-xianxia: ["境界", "灵气", "法宝", "天道", ...]
    light-novel: ["桌游域词", "物质域词", ...]
    doomsday: ["末日", "光暗", "灰烬", "棋局", ...]
```

**工程价值**：✅ 抽象为通用"领域浸入"原则——可作为 mo-writer 简报 §0 的强制字段。

### L1.3 自由间接引语作为内心通道（备选通道）

**证据**：
- 远瞳：自由间接引语 + 括号注 + 内心独白混合
- 葵关南：自由间接引语 60-70% + 第一人称吐槽 15-20%
- 风月：自由间接引语 ~10-15% + 叙述者抒情 70-80%（风月是反例）

**跨作共性**：自由间接引语是**至少 2 个作家**的核心内心通道——但风月反例证明它**不是绝对默认**。**降级为备选通道**——由 `style_profile` 决定是"自由间接引语"还是"叙述者抒情"还是"其他"。

**工程约束**：
```yaml
inner_channel_options:
  - "free-indirect-speech"  # 远瞳/葵关南默认
  - "narrator-lyrical"  # 风月默认
  - "first-person-rant"  # 葵关南第一人称吐槽
inner_channel_default: "free-indirect-speech"  # 网文主流默认
```

**工程价值**：✅ 协议级约束——sensory-writer Step 2 内心通道协议改为"按 style_profile 选择"而非"自由间接引语为唯一默认"。

### L1.4 信息差叙述（通用技法）

**三种子型**（三作家档案共同抽象出）：

| 子型 | 谁知道 | 戏剧效果 | 源作家 |
|------|--------|---------|--------|
| **双层信息差** | 读者>主角心理>外人感知 | 恐怖化+喜剧化 | 远瞳 |
| **角色自我欺骗** | 读者>主角内心>主角表达 | 温柔化+释怀化 | 葵关南 |
| **跨时空呼应** | 不同时空的同一事件 | 启示化+见证化 | 风月 |

**统一抽象**：
> **信息差叙述 = 读者/角色/配角之间存在认知差异，叙述者通过控制信息释放顺序制造戏剧效果**

**工程约束**：
```yaml
techniques:
  - name: "信息差叙述"
    type: "narrative"
    applicable_to: ["all"]
    variants: ["double-layer", "self-deception", "temporal-resonance"]
```

**工程价值**：✅ 抽象为通用技法——可入库 `framework/templates/technique-library.md` 作为"跨作家通用技法"，下分三种子型。

### L1.5 信息释放漏斗形（前密后疏）

**证据**：
- 远瞳深海：层层外翻（异常）→ 漏斗形（黎明）→ 波浪形（深海）—— **三作都有"前密"特征**
- 葵关南桌游咖 + 败犬女主：每话开篇密度高 + 收束留白
- 风月天启预报：序章密度极高 + 后段留白

**跨作共性**：开篇密度高（建立读者期待）+ 后段留白（给读者想象）—— 这是**网文"防弃文"节奏设计的核心技巧**。

**工程价值**：✅ 抽象为通用节奏技巧——可作为 mo-writer 简报 §0 风格锚点的"信息释放曲线"字段。

### L1.6 角色选择型高潮（节拍级）

**证据**：
- 远瞳三作：角色选择型高潮 15-30% 占比
- 葵关南桌游咖 + 败犬女主：核心高潮模式（节拍级失败承认）
- 风月天启预报：角色选择型 ~20%

**跨作共性**：所有 3 个作家都用"角色在关键选择点做出选择"作为高潮——但**规模不同**（远瞳大场景 vs 葵关南小光谱 vs 风月启示式）。

**工程价值**：✅ 抽象为通用高潮模式——可作为 climax-patterns 通用分类。

### L1.7 节拍密度递增规律

**证据**：
- 远瞳：早期 1.5-2.5/千字 → 后期 3.5-7/千字
- 葵关南：每话 3-5 个有意义节拍
- 风月：节拍密度 3-5 个/1000 字（与葵关南一致）

**跨作共性**：节拍密度在卷内"递增"——这是**长篇小说保持读者粘性的物理基础**。

**工程价值**：✅ 抽象为通用节奏技巧——可作为 plan-chapter 阶段 4 D9 篇幅与结构的"节拍密度递增"约束。

## 六、中国网文原生 vs 日轻翻译 差异（不可迁移维度）

> 这部分是**根本性差异**——不是作家风格，是文学传统的差异。

| 维度 | 中国网文原生（远瞳+风月）| 日轻中文翻译版（葵关南）| 工程处理 |
|------|----------------|------------------|---------|
| 推进单位 | 一次岛弧/战役/末日仪式 | 两个角色的一个完整互动 | 题材谱 + 变体 |
| 外部大事件 | 必有（神战/魔潮/末日）| 几乎无 | 题材谱 |
| 大纲设计 | 卷级建设+多线汇集 | 单话 5 节拍+小尺度 | 题材谱 |
| 关系-事件比 | 关系依附于事件 | 事件依附于关系 | 题材谱 |
| 冲突结构 | 4 层嵌套（文明×国家×领地×个人）| 1-2 层（自己×他人）| 题材谱 |
| 高潮光谱 | 大型（信息揭露+多线汇集+角色选择）| 小型（角色选择+节拍级失败承认）| 题材谱 |
| 世界观密度 | 中-极高（硬规则+多文明）| 极简现实 | 世界观密度谱 |
| 跨种族 | 必有 | 几乎无 | 题材谱 |
| 群像规模 | 10+核心+100+配角 | 5-8 核心 | 群像节拍谱 |
| 翻译腔 | 0 | 高 | 网文原生默认 0，翻译版变体启用 |
| 段长 | 极短段 1-3 句（风月）/ 中段 4-6 句（远瞳）| 极短段 1-3 句 | 作家特定 |
| 修辞密度 | 中等 | 极高（省略号 80-130/万字）| 作家特定 |

**核心结论**：
- "中国网文 vs 日轻"是**文学传统的差异**——不是作家风格
- 工程默认基底应**以中国网文原生为主**（远瞳+风月共性）——日轻作为变体可选
- 翻译腔吐槽声**不应作为网文工程默认**——是日轻翻译版中介产物

## 七、抽象为通用谱的 4 项（核心工程可入库工具）

> 这 4 项是**所有 3 个作家档案的共性抽象**——可直接入库为工程通用工具。

### 谱 1：信息差叙述（通用技法）

**统一抽象**：
> 信息差叙述 = 读者/角色/配角之间存在认知差异，叙述者通过控制信息释放顺序制造戏剧效果

**三种子型**：
- `double-layer`（远瞳式）：读者>主角心理>外人感知
- `self-deception`（葵关南式）：读者>主角内心>主角表达
- `temporal-resonance`（风月式）：不同时空的同一事件

**工程约束**：
```yaml
techniques:
  - name: "信息差叙述"
    applicable_to: ["all"]
    variants: ["double-layer", "self-deception", "temporal-resonance"]
```

**入库存档**：`framework/templates/technique-library.md` 跨作家通用技法分类

### 谱 2：群像节拍谱（三轴）

**统一抽象**：
> 群像节拍谱 = 规模-互动模式-频次分布三轴

**三轴档位**：
- **规模**：`small-tight` / `small-loose` / `ensemble` / `starfield` / `revelation-witness`
- **互动模式**：`central` / `parallel` / `stepped` / `interleaving` / `revelation`
- **频次分布**：`uniform` / `stepped` / `pulsed` / `revelation`

**工程约束**：
```yaml
ensemble_beat:
  size: ...
  interaction_mode: ...
  frequency: ...
```

**入库存档**：`framework/templates/author-analysis-7d.md` 维度 3 关系设计模式 + 维度 1 叙述者风格（互动模式）

### 谱 3：世界观密度谱（四档）

**统一抽象**：
> 世界观密度谱 = 轻/中/中重/重

**四档**：
- `minimal`（极简）：葵关南（桌游咖+败犬女主）
- `moderate`（中）：风月（末日背景+启示）
- `heavy`（中重）：远瞳黎明/异常（硬规则+多文明）
- `extreme`（重）：远瞳深海（多层深渊+古神体系）

**工程约束**：
```yaml
worldview_density: "minimal" | "moderate" | "heavy" | "extreme"
```

**入库存档**：`framework/templates/author-voice.md` 新增"世界观密度"字段 + `framework/templates/reference-material.md` §世界构建分类

### 谱 4：情绪温度谱（四档）

**统一抽象**：
> 情绪温度谱 = 冷/温/暖/烫

**四档**：
- `cold`（冷）：远瞳（叙述者距离+冷吐槽）
- `warm`（温）：葵关南（自嘲+吐槽+麻省）
- `hot`（暖）：风月（末日抒情+金句）
- `scalding`（烫）：言归正传（崇拜式抒情）

**工程约束**：
```yaml
emotional_temperature: "cold" | "warm" | "hot" | "scalding"
```

**入库存档**：`framework/templates/voice-bible.md` §1.2 语调范围表

## 十、葵关南默认档案的最终定位

>
> **正确的工程默认**应该是"L1 网络原生共性 + L2 题材谱"——葵关南档案只是其中一个 L3 作家档案。
