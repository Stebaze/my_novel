# C8：Handoff 文件验证（v2.0——12 字段 + 5 维正交风格档案）

**条件**：scope="writing"，🚫 **硬阻断入口**

> 4-Skill 对称架构的入口硬检查——`generate-chapter` 启动时必须验证 plan→generate 跨 Session 状态交接文件存在且契约完整。完整契约见 `framework/_specs/interaction-spec.md` §2.4。
> v2.0：style_profile 单字段 → 5 维字段组合（type/themes/variant/subvariant/specialization）。

## 步骤 1：文件存在性

```
目标文件：{draft_dir}/_briefs/chapter-{N}-handoff.md
├── 不存在 → 🚫 硬阻断：
│   "Ch{N} handoff 缺失——必须先调 plan-chapter（阶段 0-5），
│    plan-chapter 完成后会自动写 handoff。或用户在新 session 输入
│    /generate-chapter {N} 触发后续生成（前置条件：plan-chapter 已完成）"
└── 存在 → 进入步骤 2（12 字段契约验证）
```

## 步骤 2：12 字段契约验证

按 `framework/_specs/interaction-spec.md` §2.4 定义的 12 字段逐一验证：

| 字段 | 类型 | 必填 | 校验 |
|------|------|:---:|------|
| `chapter` (int) | int | ✅ | 缺失或值 ≠ N → 🚫 |
| `direction` (path) | path | ✅ | 缺失或文件不存在 → 🚫 |
| `brief` (path) | path | 🟡 | workflow_position 前缀为 `generate-*` 时必填；缺失或文件不存在 → 🚫 |
| `chapter_file` (path) | path | ✅ | 缺失或路径不以 `chapters/` 开头 → 🚫 |
| `character_state` (path) | path | ✅ | 缺失或文件不存在 → 🚫 |
| `style_profile_type` (string) | string | ✅ | 缺失或对应 `framework/templates/_style-bases/{type}.md` 文件不存在 → 🚫 |
| `style_profile_themes` (list[string]) | list[string] | ✅ | 缺失或空列表，或任一对应 `framework/templates/_themes/{theme}.md` 文件不存在 → 🚫 |
| `style_profile_variant` (string) | string | 🟡 | 非空时但对应 `framework/templates/_styles/{variant}.md` 文件不存在 → 🚫 |
| `style_profile_subvariant` (string) | string | 🟡 | 非空时但对应子变体文件不存在（嵌入在 {variant} 风格层文件中）→ 🚫 |
| `style_profile_specialization` (string) | string | 🟡 | 非空时但对应 `framework/templates/_style-bases/specializations/{specialization}.md` 文件不存在 → 🚫 |
| `workflow_position` (string) | string | ✅ | 缺失或格式不符（不含三段式）→ 🚫；前缀非 `plan-` / `generate-` / `review-` → 🟡 |
| `resume_command` (string) | string | ✅ | 缺失或格式不符（不以 `/` 开头）→ 🚫 |

`path` 字段以 `{draft_dir}` 为根的相对路径。`workflow_position` 用 `<skill>-<step>-<artifact>` 三段式。
5 维字段的值参考 `framework/templates/_style-bases/` / `_themes/` / `_styles/` 下的文件名（profile_id 字段）。

## 步骤 3：输出

- 全部 ✅ 通过 → 报告 "Handoff 验证通过：{N} 12 字段全填入 + 5 维风格档案已确认 + 简报状态={have_brief}"
- 任一 🚫 → 报告 + 修复路径：
  - "调 `plan-chapter {N}` 重跑阶段 5（settings-manager record-handoff v2.0）"
  - "或手动：复制 `framework/templates/chapter-handoff-template.md`（v2.0，12 字段）→ 填写 5 维风格档案字段"

## 降级

- `{draft_dir}` 不可用（无草稿）→ 跳过 C8（无草稿即无 handoff 概念，scope="writing" 应在草稿初始化后执行）
- frontmatter 解析失败（YAML 损坏）→ 🚫 "handoff 文件 frontmatter 解析失败，请校验 YAML 语法"
- 5 维字段对应文件不存在 → 🚫 硬阻断并提示文件路径（如 "基底 japanese-light-novel-base-v1.2 不存在——检查 `framework/templates/_style-bases/` 目录"）
