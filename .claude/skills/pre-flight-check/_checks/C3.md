## author-voice 条件性降级（2026-07-01 修复）

`author-voice.md` 是否必须存在取决于 `novel/project-config.md` 的「作家」字段：

```
读 project-config.md frontmatter `作家` 字段
├── 字段为空字符串 ("") 或缺失：
│   → author-voice.md 不是必需——走风格 fallback 层（framework/templates/_styles/{风格}.md）
│   → 降级为 ⚠️（"作家字段空，走风格 fallback，author-voice.md 缺失"）
│   → 不阻断
├── 字段非空（指定了具体作家）：
│   → 查 profiles/authors/{作家}.md
│   ├── 存在 → ✅ 通过（author-voice 已在 profiles/authors/）
│   └── 缺失 → 调 qing-novelist（作者分析模式：7 维作者风格分析）建立档案
│       ├── 成功 → ✅
│       └── 失败 → 🚫 硬阻断
```

> **修复历史**：v1.0 spec 标 `author-voice.md` 缺失 → 🚫 硬阻断，但未考虑 `作家=""` 走 fallback 的场景。
> 2026-07-01 E2E 验证 Ch2 暴露此问题——`作家=""` 项目被误阻断。修复：增加条件性降级。
>
> **适用性**：所有走 fallback 风格层（`风格: "kuiguannan-style-fallback-v3"` 等）的项目自动受益。

## 执行

缺失 → 调 `Skill("file-manager", operation="ensure-novel")`。
