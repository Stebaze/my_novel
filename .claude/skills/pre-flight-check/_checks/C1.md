# C1：草稿目录检测

## 检查逻辑

检查固定路径 `novel/_drafts/` 存在性（单草稿约束，无日期目录扫描）。

- 存在 → `draft_dir = novel/_drafts/`，状态 ✅
- 不存在 → 标志"需初始化"（由 plan-chapter 调 `settings-manager` (init-draft) → file-manager (ensure-draft) 建空模板+目录）

**不再扫描"最新日期目录"**——单草稿扁平化，固定路径贯穿全书复用。

## 输出

`draft_dir = "novel/_drafts/"` + 初始化状态（✅ / ⚠️ 待初始化）。
